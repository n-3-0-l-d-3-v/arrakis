# Constraint Matrix

| Layer | Constraint | What it forces |
|---|---|---|
| THE MACHINE | The machine does not use a conventional instruction-pointer-driven execution model. Instructions execute when their operand dependencies become ready, not in program-counter order. | Fixed-size instruction encoding, bounded physical registers, explicit operand dependency tracking, deterministic scheduling, and deterministic replay. |
| THE LANGUAGE | The compiler avoids a conventional multi-pass AST-centered architecture, preferring a typed SSA/CPS-like representation directly from parsing. | Alternative intermediate representation design, and a compiler front-end that must justify every conventional structure it keeps. |
| THE KERNEL | There is no hierarchical path resolution anywhere in the system, no trusted wall clock, and all resource access happens through explicit capabilities. | Capability passing, IPC, logical/vector clocks for ordering, and object-reference-based resource naming instead of paths. |
| THE VAULT | Persistent storage may never overwrite an existing byte. A logical update produces a new version; a deletion produces a tombstone; compaction produces a new representation without mutating the old one. | Versioning, MVCC, append-only logs, page/segment design, and a real compaction and reclamation policy. |
| THE DATABASE | The database must run entirely on the project's own immutable storage engine, starting from PUT/GET/DELETE/SCAN/SNAPSHOT before any relational layer exists. | Transactions and MVCC on top of an append-only substrate, real concurrent-client testing, and a constrained SQL subset built bottom-up. |
| THE WIRE | The underlying channel provides no ordering, no reliable delivery, no framing, no integrity, and duplicates or corrupts datagrams. All of that must be built at this layer. | Framing, checksums/integrity, sequence numbers, ACKs, retransmission, selective repeat, flow control, and RPC with idempotency. |
| THE COLONY | Nodes communicate only over distrans, storage is still append-only, there is no global clock, and any node may crash at any time. | Leader election, log replication, quorum commitment, and recovery that never silently produces an invalid committed state. |
| THE HISTORY | Every object is immutable and content-addressed. History forms a DAG. Diffs are computed on demand, never stored as the primary historical representation. | Content-addressed object storage on top of sietch, DAG traversal, and network synchronization over distrans. |
| THE ARTIFACT | A standard, ordinary-looking data file (PDF/SVG/font/etc.) becomes the container for a real computation environment: loader, VM, and shell. | Polyglot file construction, a tiny trusted loader, and running mentat's VM from inside a non-executable substrate. |
