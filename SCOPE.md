# Scope

## CORE — required for Level 2 (the official fallback)
- mentat: deterministic dependency-driven execution
- sietch: append-only storage, recovery, compaction
- distrans: reliable transport over a hostile channel, RPC
- landsraad: 3-node replication + consensus + chaos testing

## EXTENSION — required for Level 3 (the full Arrakis ecosystem)
- chakobsa, muaddib, choam, ghola

## EXPERIMENT — only attempted once CORE + EXTENSION are healthy
- shai-hulud
- alternative execution models, LSM comparisons, advanced sharding

## Explicitly excluded from the critical path
Full Linux/TCP/SQL compatibility, Byzantine consensus, production congestion
control, a GUI desktop environment, ten-node "production" clusters, cloud
deployment, blockchain, AI-driven anything.
