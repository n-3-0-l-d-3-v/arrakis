# Scope

## CORE — required for Level 2 (the official fallback)
- impossible-machine: deterministic dependency-driven execution
- impossible-vault: append-only storage, recovery, compaction
- impossible-wire: reliable transport over a hostile channel, RPC
- impossible-colony: 3-node replication + consensus + chaos testing

## EXTENSION — required for Level 3 (the full Impossible Computer)
- impossible-language, impossible-kernel, impossible-database, impossible-history

## EXPERIMENT — only attempted once CORE + EXTENSION are healthy
- impossible-artifact
- alternative execution models, LSM comparisons, advanced sharding

## Explicitly excluded from the critical path
Full Linux/TCP/SQL compatibility, Byzantine consensus, production congestion
control, a GUI desktop environment, ten-node "production" clusters, cloud
deployment, blockchain, AI-driven anything.
