# Getting help

ARRAKIS is an experimental project maintained by one person in their own
time. There is no commercial support and no guaranteed response time.

| You want to… | Go to |
|---|---|
| install it or run the demos | [INSTALL.md](INSTALL.md), then [docs/DEMOS.md](docs/DEMOS.md) |
| understand how a subsystem works | [docs/GUIDE.md](docs/GUIDE.md) and the subsystem's `docs/design/` ADRs |
| use the CLI for something specific (`--json`, replay, scripting) | [docs/WORKFLOWS.md](docs/WORKFLOWS.md) |
| ask a question or discuss a design | [Discussions → Q&A or Ideas](https://github.com/n-3-0-l-d-3-v/arrakis/discussions) |
| report something that is broken | [a bug report](https://github.com/n-3-0-l-d-3-v/arrakis/issues/new/choose), with the command, the seed and your platform |
| report a security problem | privately, as in [SECURITY.md](SECURITY.md) |
| contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

Before opening an issue, check the README's "Limits and non-goals" and
[ROADMAP.md](ROADMAP.md): many things that look like bugs are documented
limits (simulated networks, the restricted PDF subset, no signatures).
